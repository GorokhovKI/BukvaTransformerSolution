#Обзор
Выпускная квалификационная работа магистра на тему "Исследование структур динамических изображений и разработка алгоритма отслеживаиня движений"
Ключевые точки кистей извлекаются при помощи MediaPipe Hands (21 точка на каждую руку), нормализуются относительно запястья, 
после чего последовательность кадров подаётся в SignLanguageTransformer. 
В режиме демонстрации предсказанные буквы накапливаются в субтитровой строке с порогом уверенности и счётчиком стабильности.
Поддерживаемые классы: все 33 буквы русского алфавита.
