## Обзор

Система распознавания жестов русского жестового языка (РЖЯ) в реальном времени на основе Transformer-архитектуры и скелетных признаков кисти.

Ключевые точки кистей извлекаются при помощи **MediaPipe Hands** (21 точка на каждую руку), нормализуются относительно запястья, после чего последовательность кадров подаётся в `SignLanguageTransformer`. В режиме демонстрации предсказанные буквы накапливаются в субтитровой строке с порогом уверенности и счётчиком стабильности.

> **Поддерживаемые классы:** все 33 буквы русского алфавита —
> `А Б В Г Д Е Ё Ж З И Й К Л М Н О П Р С Т У Ф Х Ц Ч Ш Щ Ъ Ы Ь Э Ю Я`

## Быстрый старт

### 1. Предобработка данных

Скрипт читает аннотации датасета **Bukva** (`data/annotations.tsv`) и извлекает скелетные признаки из видеофайлов.

```bash
python preprocess.py
```

Результат — `.npy`-файлы в папке `features_data/` и сводный `metadata.npy`.

**Формат аннотаций (`annotations.tsv`):**

| `attachment_id` | `text` | `train` |
|---|---|---|
| 00123 | А | True |
| 00124 | Б | False |

### 2. Обучение модели

```bash
python train.py
```

По завершении лучший чекпоинт сохраняется в `best_model_bukva.pth`, графики — через `plot.py`.

### 3. Демонстрация в реальном времени

```bash
python demo.py
```

> Требуется: чекпоинт `best_model_bukva.pth` и подключённая веб-камера.

**Управление:**

| Клавиша | Действие |
|---|---|
| `Q` | Выход |
| `Space` | Добавить пробел в субтитры |
| `Backspace` | Удалить последний символ |
| `C` / `С` | Очистить субтитровую строку |

## Архитектура модели

```
Входная последовательность (80 кадров × 126 признаков)
             │
             ▼
      ┌─────────────────┐
      │  TemporalStem   │  delta-признаки + Conv1d + GELU
      └────────┬────────┘
               │
               ▼
      ┌─────────────────┐
      │  CLS-токен  +   │
      │  Positional Enc │  синусоидальное кодирование
      └────────┬────────┘
               │
        ┌──────┴──────┐
        │  Transformer │  2 блока, 4 головы, hidden=128
        │    Blocks    │
        └──────┬───────┘
               │
               ▼
      ┌─────────────────┐
      │  LayerNorm →    │
      │  Linear(128→33) │  33 класса (буквы алфавита)
      └─────────────────┘
```

Ключевые гиперпараметры:

| Параметр | Значение |
|---|---|
| `SEQUENCE_LENGTH` | 80 кадров |
| `INPUT_SIZE` | 126 (2 руки × 21 точка × 3 координаты) |
| `HIDDEN_SIZE` | 128 |
| `NUM_HEADS` | 4 |
| `NUM_LAYERS` | 2 |
| `DROPOUT` | 0.3 |
| `LEARNING_RATE` | 1e-4 |
| `EPOCHS` | 150 |

```python
# preprocess.py → normalize_landmarks()
centered   = coords - wrist           # центрирование по запястью

normalized = clip(centered / scale, -5.0, 5.0)
```
